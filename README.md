# Квартал ☭
Карта 60 × 60 с пиксельными гаражами, ЗИЛом, школой, заводом и панельками. Анимированные прохожие, дым и фонарь (с учётом prefers-reduced-motion). Пиксельный вымышленный город в стилистике советского плаката. Бесплатные участки, название, текст, ссылка и цвет. Без регистрации, публикация сразу.

## Запуск
Node.js 22 или новее. Внешние пакеты не нужны.

```sh
npm ci
npm start
```

Сервер слушает порт 3000 (можно изменить через PORT). Объявления всех посетителей сохраняются в `data/ads.json`. DATA_DIR позволяет задать отдельную директорию. Для публичного сервера необходимо постоянное хранилище. Запускайте один экземпляр сервера с одним хранилищем.

`npm test` проверяет создание, чтение, валидацию и конкурирующее занятие участка.

## GitHub Pages
Workflow `.github/workflows/pages.yml` публикует папку `public` при push в main. В настройках Pages источник должен быть GitHub Actions. Относительные пути поддерживают размещение в /advert/.

GitHub Pages не запускает Node.js. На github.io включается явно обозначенный деморежим: объявления хранятся только в localStorage посетителя. Для общей карты нужен отдельно размещённый сервер и подключение фронтенда к нему. Это остаётся отдельным шагом; Pages не является общим хранилищем.

## Ограничения первой версии
Нет аккаунтов, редактирования, удаления, модерации и защиты от массового занятия. Не публикуйте личные данные. Ссылки разрешены только HTTP/HTTPS; пользовательский текст отображается как текст. Перед полноценным публичным запуском общего сервера нужна защита от злоупотреблений.

## Жизнь города
96 жителей с самостоятельными маршрутами и состояниями: движение, покупки, работа, отдых, разговоры и короткие неграфические потасовки. BFS-маршруты обходят здания. После покупки жители несут пакет домой, за работу получают деньги. Доступны пауза и скорость ×1/×2/×4. Клик по жителю показывает имя, профессию, занятие и деньги. Хроника отражает последние события. Симуляция выполняется в браузере, не синхронизируется между посетителями и автоматически сохраняется в localStorage каждые 5 секунд и восстанавливается при перезагрузке; скрытая вкладка приостанавливает её. При prefers-reduced-motion запуск на паузе.

## Симуляция района
40 мест, 24 семьи и 96 взрослых жителей. Семья делит дом, бюджет и продукты. Работа приносит зарплату, магазины тратят запасы и получают доставку, покупки пополняют кладовую дома. Голод, усталость, время суток, погода и потребность в общении влияют на выбор следующего занятия. Один реальный секундный шаг — две игровые минуты; день — 12 минут при скорости ×1. Есть ежедневные коммунальные платежи, смена дня/ночи и погода; в дождь жители идут медленнее.

Персонажи разговаривают несколькими репликами, конфликтуют из-за быта и шума, запоминают напряжённые отношения и могут мириться при следующей встрече. Реплики — DOM-текст поверх карты, без растрового размытия; полные разговоры доступны в хронике. Клик по записи переносит карту к месту события. Карточка жителя показывает семью, бюджет, еду и потребности.

Состояние семей, маршрутов, отношений, запасов и игрового времени сохраняется локально. «Новая история» сбрасывает симуляцию после подтверждения, сохраняя объявления. Симуляция не продолжает работать при закрытой/скрытой вкладке и не синхронизируется с другими посетителями. Это автономный браузерный симулятор, без серверной круглосуточной симуляции.
